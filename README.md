# 🎂 Age Calculator — I BUILD #06/80

A clean, responsive Age Calculator built using **HTML, CSS, and JavaScript**.

This project is **#06 of my I BUILD — 80+ Projects** challenge, where I build projects consistently to improve my frontend development, JavaScript, UI/UX, and problem-solving skills.

## ✨ Features

- 📅 Displays today's date
- 🎂 Birthdate input
- 🧮 Calculates exact age
- 📆 Displays age in years, months, and days
- ⚡ Real-time age calculation
- 🔄 Reset functionality
- ⚠️ Input validation
- 📱 Responsive design
- 🎨 Clean and modern UI

- DOM Manipulation
- JavaScript Date Object
